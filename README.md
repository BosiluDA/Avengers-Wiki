# Avengers Wiki

## Why
Class task 06 - Avengers fan site with character list and sign up. Shows AJAX, database, and CRUD.

## Tech
- HTML, CSS, Bootstrap, jQuery
- PHP + MySQL (PDO)

## How to Run

1. Start XAMPP (Apache + MySQL)

2. Create database – in phpMyAdmin, import `setup_database.sql`
   - Or: `mysql -u root < setup_database.sql`

3. Open in browser:
   - `http://localhost/Group-24(Class%20Task-06)/Group-24(Class%20Task-06)/index.html`

4. Login: `login/login.html`
